# موقع أحمد ال علي TV

موقع ترحيبي ثابت باللغة العربية، متجاوب مع الهاتف والكمبيوتر، بألوان الأسود والأزرق السماوي وخط Cairo.

## الملفات
- `index.html` — محتوى الموقع.
- `style.css` — التصميم والألوان والخطوط.
- `script.js` — السنة الحالية وحركة ظهور بطاقات المميزات.

## المعاينة
افتح `index.html` في المتصفح. يحتاج اتصال إنترنت لتحميل خط Cairo من Google Fonts؛ وسيعمل مع خط بديل عند عدم توفره.

## النشر مجاناً عبر GitHub Pages
1. سجّل الدخول إلى GitHub وأنشئ مستودعاً جديداً (Repository)، مثلاً `ahmed-ali-tv`.
2. ارفع الملفات الثلاثة `index.html` و`style.css` و`script.js` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.

ملاحظة: هذه واجهة ترحيبية ثابتة فقط. لا تحتوي على بث تلفزيوني أو تسجيل دخول أو لوحة إدارة أو روابط تنزيل تطبيق؛ يمكن إضافتها عند توفير التفاصيل والروابط الصحيحة.
